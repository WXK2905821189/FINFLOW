## 二、取证方法（可复现）

**第 1 步：从元数据读出「槽位 → 维度名」**
```
QueryBusinessInfo(FormId=GL_VOUCHER) → 遍历字段，取 Key 以 FDETAILID__ 开头者，
其 Name(2052) 即金蝶侧维度名。
```
得到 13 个：`FFLEX4`供应商…`FFLEX13`客户分组、`FF100002`银行账号、`FF100003`项目、`FF100004`投资人。

**第 2 步：维度编码对齐**
```
ExecuteBillQuery(BD_FLEXITEMPROPERTY, FNumber,FName) →
HSWD01_SYS 供应商 / HSWD02_SYS 客户 / HSWD03_SYS 部门 / HSWD04_SYS 员工 /
HSWD05_SYS 物料 / HSWD06_SYS 资产类别 / HSWD07_SYS 费用项目 / HSWD08_SYS 组织机构 /
HSWD09_SYS 物料分组 / HSWD10_SYS 客户分组 / ZDY0001 银行账号 / ZDY0002 项目 /
ZDY0003 投资人 / ZDY0004 合同号
```
规律自洽：标准维度按序占 `FFLEX4~13`，自定义维度按序占 `FF100002+`；其中
`FF100002=银行账号` 早已被凭证 16043 独立实测，构成交叉验证。

**第 3 步：报错驱动实证**（关键，把推断变成证据）

| 凭证号 | 内容 | 结果 |
|---|---|---|
| 基线 | 借方 `1221.01 保证金` 不带任何维度 | 报错：`第1行分录：科目（1221.01-保证金）设置的下列必录维度未录入或不可用：供应商` |
| **16059** | 同上 + `FFLEX4=VEN00001` | ✅ 保存成功 → 立即删除 |
| **16060** | `1221.01`+`FFLEX4`、`2241.04`+`FFLEX7=001`、`1122.01`+`FFLEX6=北分108` 三槽位同凭证 | ✅ 保存成功 → 立即删除 |

两张实证凭证均已删除并回查为空（`ExecuteBillQuery` 返回 `[]`），账套内不留痕。

**推论（供后续复用）**：槽位不必逐个盲试——**先读元数据的字段 Name，再用 1~2 张凭证交叉实证即可**。
本次 3 个槽位合计只用了 3 次 Save 请求。
