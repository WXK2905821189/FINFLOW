# 星空OpenAPI介绍

背景

企业的IT建设过程中会发现某一家软件供应商提供的软件不能完全覆盖企业所有的业务运营流程，因此企业可能从不同软件供应商购买了不同的系统，比如ERP、OA、HR、CRM、PDM等。所有的业务由不同系统覆盖，但由于系统未集成，而形成了一些新的信息孤岛，不利于企业的后续的管理和战略发展。

鉴于企业经营、IT建设的多样化，为了企业不同软件之间实现数据共享，星空OpenAPI应运而生。

星空OpenAPI将各个业务领域的所有业务功能通过标准的接口开放，提供给第三方系统调用，使第三方系统能轻松的实现与星空产品的集成。

实现技术

星空 OpenAPI是一种轻量级的、可维护的、可伸缩的 Web 服务。采用HTTP+JSON，也就是用RESTful的方式来开发。使用.NET Framework 4.0为开发平台，源代码使用C#编写。

功能

星空OpenAPI已实现18个标准接口，1个自定义接口，提供对星空产品的所有单据和基础信息的查看、保存、提交、审核、反审核和删除等功能，业务领域涵盖了财务会计、PLM、供应链、电商与分销、客户关系管理、生产制造等。并能通过自定义接口，在星空实现定制化业务功能，开放给第三方系统调用。

使用方式

       星空OpenAPI SDK提供了.Net、Java和Python三种语言版本的SDK，SDK采用加密签名技术，避免密钥的明文传输，实现自动登录，加密会话管理。推荐用户使用官方的SDK。对于有特殊需求的开发者，也可以自行通过http请求。
