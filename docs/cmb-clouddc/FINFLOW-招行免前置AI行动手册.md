## 阶段 0｜现在 → 联调环境下发（预计 9/4-9/11 窗口，红线 9/10）

> 此阶段目标：**银行侧测试资源一旦下发，FINFLOW 代码能当天开跑联调**。
> 联调环境下发前唯一需要"人等环境"的事是密钥生成与上传（也要等测试资源里的 UID）。

### 0.1 交给 AI 立刻做（全栈工程师对话，9/5 内完成）

| # | 任务 | 说明/验收 | 依赖 |
|---|---|---|---|
| T1 | **建立 cmb 适配器骨架**（仿 `adapter/citic/` 包） | `adapter/cmb/` 建包：Properties/CryptoHelper/HttpGateway/RequestBuilder/ResponseParser/RealAdapter，可编译、单测空跑 | 无 |
| T2 | **移植加密核心** `CmbCryptoHelper` | 从 `samples/免前置Demo/Api/Java/DcHelper.java` 移植：SM2签名(SM2withSM3)+SM4-CBC+ASCII排序+reqid生成。**用 demo 内置测试密钥跑通自测**（明文密钥仅测试位） | 无 |
| T3 | **CI 契约测试**（fake 网关） | 仿中信做法：本地起 fake HTTP 网关，验「排序→签名→加密→发 POST(UID/ALG/DATA/FUNCODE)→解密→解析」全链路断言 | T1,T2 |
| T4 | **余额/流水报文构建** | `CmbBalanceQuery`(NTQADINF ≤30账户)、`CmbStatementQuery`(trsQryByBreakPoint + Y1 续传) 按接口文档字段构造 | T1 |
| T5 | **响应→BankDataCollection 映射** | Z2 明细→BankDataEntry(方向/金额/时间/对手)；`ctnFlag=Y`→`hasMore=true`、`queryAcctNbr`→`nextCursor`；幂等键设计（日期+金额+对手+摘要组合） | T4 |
| T6 | **配置位** `CmbAdapterProperties` | url(测/产)/uid/privateKey/publicKey/symKey + real-enabled 双保险开关，**敏感项走环境变量** | T1 |

## 阶段 1｜联调环境下发 → M1 联通（9/12-9/18）

> 目标：真实连上 `cdctest.cmburl.cn`，NTQADINF + trsQryByBreakPoint 跑通，**9/18 输出联通报告**。

### 1.1 给 AI 的任务（联调启动即做）

| # | 任务 | 说明 |
|---|---|---|
| T7 | **真实参数接入**：把 UID/密钥/测试 URL 配进环境变量 → 冒烟 DCLISMOD(可经办模式) → NTQADINF(余额) | 按 T6 配置位，**参数不落库不进 git** |
| T8 | **联调脚本**：余额批量查 + 流水断点续传 3 页（>200 条验证 ctnFlag 续传） | 记录每个接口原始请求/响应各 1 份到 `docs/cmb-联调记录/` |
| T9 | **边界用例**：无权限账户、空结果、超大日期窗口、错误密钥(验签失败)、CDCServer: 网关错 | 每类记录返回码与处理 |
| T10 | **修复+固化**：联调中发现的问题修复，回归 CI | 与 0.1 的契约测试对照 |
| T11 | **联通报告**：接口清单+测试数据+截图/报文样本+问题清单 | 给 PM（你）验收 |

- [ ] 联通报告产出（M1 交付物）
