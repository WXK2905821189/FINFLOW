## 抓取方法（可复用）

端点均为公开 API，**免登录**：

```
# 1. 目录树
POST /fbdev/v2/public/document-center/document-catalog/find-catalogs
     {"bizkey":"DCCT20201215110811035"}

# 2. 正文 (nwcdls 一次传全部节点 id)
POST /fbdev/v2/public/document-center/document-catalog/contents
     {"nwcdls":["节点id1","节点id2",...]}
     → infBdy.pageList[].dccicn = HTML 正文 (含 base64 内嵌截图)
```

转 Markdown：`tmp/cmb-to-md.py`（HTML→文字+base64 图落盘 → 相对路径引用）。

## 官方示例代码（新增 ⭐ 高价值）

文档「5.示例代码」指向官网下载中心，已直接抓取 **3 个核心 zip** 到 `samples/`（下载中心共 9 个文件，其余 6 个与对接无关未取）：

```
docs/cmb-clouddc/samples/
├── 免前置Demo/            ← ⭐ 免前置国密对接示例（5 语言：Java/C#/Php/Python/nodejs）
│   └── Api/Java/          ← Java 8 + gson 2.8.6 + bcprov 1.61, 包名 cmb
│       ├── DcHelper.java  ← 核心: SM2签名 + SM4加解密 + HTTP报文
│       └── ApiDemo.java   ← 调用示例
├── SaaSDemo/              ← SaaS 模式国密示例（同 5 语言）
├── 国密生成工具/          ← SMKeyTool.exe 密钥生成工具（含 CMBSMDLLKY.dll）
├── 免前置Demo.zip / SaaS Demo.zip / 国密生成工具-0418.zip
└── (下载记录: tmp/cmb-files.json, tmp/cmb-want.json)
```

**对 FINFLOW 的价值**：`DcHelper.java` 即免前置对接的完整可参考实现——SM2-with-SM3 签名、SM4-CBC 加解密、请求排序/签名/加密/发送/解密全链路，改造为 Spring Boot 3 服务时可直接对照。
