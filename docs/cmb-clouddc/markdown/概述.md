【概述】 

账户管理主要用于查询本单位账户信息或集团公司查询全国范围内在招商银行开户的子公司账户信息，包括查询账户详细信息、账户交易信息、账户实时余额、账户历史余额以及电子回单信息。

通常用户在开发的时候，可以按照“查询账户余额—&gt;查询交易流水—&gt;查询电子回单”的思路进行开发，具体可以根据用户的实际需求选择开发哪些接口。一般用户通常开发三个接口：账户详细信息查询(NTQACINF)用于查询账户余额，账户交易信息查询trsQryByBreakPoint接口用于查询账户交易流水，电子回单异步查询（ASYCALHD）查询电子回单图片， 由于账户交易查询和电子回单查询返回数据量大，而直联查询功能与除支付、代发、代理清算之外的其他业务功能共用20并发，受并发限制，如无特殊需求建议当天查询前一天的数据，每天查询一次即可。 账务查询相关接口目前整点、半点请求并发量很大，响应耗时比其他时间点明显增加，请避免整点、半点向银行发起查询。 

 【注意】 

 报文结果判断逻辑：当返回报文head节点中resultcode字段为SUC0000时，表明请求已经被银行成功接收，不代表业务处理成功，业务处理结果请调用各个业务查询接口进行判断。返回其他错误码时，如果是查询类的请求可以直接重发，如果是经办类请求请先调用相应业务的查询接口判断之前请求是否有成功送达银行，确认没有记录后可以重发之前的请求，请注意：重发时请保证请求报文里面的业务参考号字段和之前请求里面的业务参考号一致（有特殊说明的接口除外），否则存在重复提交的风险。其他错误代码的描述请参见resultmsg的错误描述。
