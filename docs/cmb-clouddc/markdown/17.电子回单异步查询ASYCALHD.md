17.&nbsp;电子回单异步查询ASYCALHD 

 使用场景 

 该接口主要用于打印交易流水回单（OFD，PDF），采用异步方式。支持续传查询。起始、结束日期范围不能超过100，可以查到5年以内的数据。

 建议每天查前一天的数据，不要重复多次调用。 

 使用说明 

 （1） &lt;rrcflg&gt;打印标志判断字段非必填，如果传空查回全量回单。如果传值则按照打印标志的值筛选。如不从网银打印回单，取值为1即可 。 

 （2）“回单文件命名中的流水号”字段可以与账户交易信息查询 trsQryByBreakPoint请求返回接口transSequenceIdn 字段一一对应，进行匹配。每一笔支付或者代发经办中的 YURREF 字段可以与交易流水中的 YURREF 一一对应，从而可以实现每一笔经办的支付 / 代发业务与交易流水 &amp; 电子回单的一一匹配。 

 （3） 代发业务如果记账方式是汇总记账，回单中不显示收款方信息，查看代发明细收款人信息可通过网银UBANK客户端-代发代扣-代发业务明细对账单，进行批量信息导出或批量对账单打印。 

 （4）该接口后台是异步处理的， 同一账号银行后台最多同时处理10个任务，超过10个任务则会提示“待处理任务数超过上限，请稍候再试”，待前面处理完后再继续发起。

（5）文件命名规则：账号_起始日期_结束日期_回单编号_流水号（有部分回单没有流水号字段）。

 （6）支持增量查询，即记住上次最后的续传内容，下次只查新增的回单。
