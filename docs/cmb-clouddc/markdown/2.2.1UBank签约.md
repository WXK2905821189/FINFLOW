2.2.1客户经理行内无纸化平台申请，客户在UBank签约 

 由客户经理从行内无纸化平台发起申请，审批通过后， 会在网银客户端生成签约待办（同时会有邮件、短信提醒）。 网银管理员 需要登录企业网银（Ukey登录）在企业网银客户端进行自助签约开通 （ 需要在网银上开通自助申请功能 ）。单管理员签约完成后生效，双管理员，还需要另一个管理员进行审批才能生效。

（1）管理员可以从 自助申请-经办 进入签约界面



![2.2.1UBank签约 图1](assets/2.2.1UBank签约-1.png)


 或者从网银首页待办 通知进入签约界面



![2.2.1UBank签约 图2](assets/2.2.1UBank签约-2.png)


 进入后，点击其他业务-银企直联-申请。 



![2.2.1UBank签约 图3](assets/2.2.1UBank签约-3.png)


 选择标准模式银企直联，点击申请 



![2.2.1UBank签约 图4](assets/2.2.1UBank签约-4.png)


 （2）查阅协议，确认月度费用。 



![2.2.1UBank签约 图5](assets/2.2.1UBank签约-5.png)


 检查费用信息，确认无误后点击同意。 



![2.2.1UBank签约 图6](assets/2.2.1UBank签约-6.png)


（3）进入银企直联设置页，用户可根据自己的需要决定是否进行银企直联设置， 选择暂不设置 直接展示操作返回结果，签完协议后，到 网银设置-企业 管理-银企直联-接入设置 菜单 进行设置。

 选择接入方式： 

 标准模式云直联预设接入模式可以选择“前置机接入”和“免前置机接入”两种接入模式 

 注意，一定要关注该界面的可经办业务，只有在企业开放平台测试且验收通过的业务才会在这里展示，才能通过直联发起请求。 



![2.2.1UBank签约 图7](assets/2.2.1UBank签约-7.png)


 第二步为用户选择，需要选择经办人员 才可以进行下一步的操作。



![2.2.1UBank签约 图8](assets/2.2.1UBank签约-8.png)


 IP白名单非必填项，可设置IP白名单，也可直接点击下一步。如暂不设置IP白名单，也可后续进入系统管理-银企直联-设置与授权-IP白名单设置菜单 进行设置。



![2.2.1UBank签约 图9](assets/2.2.1UBank签约-9.png)


 添加相关信息 中，用户需要填写接入模式的对接系统信息，并各设置至少一名财务联系人和技术联系人的信息，最大可以设置5名；确认填写信息无误后，点击提交，提示 经办成功，请通知各级审批人完成业务审批。 



![2.2.1UBank签约 图10](assets/2.2.1UBank签约-10.png)




![2.2.1UBank签约 图11](assets/2.2.1UBank签约-11.png)


（4）直联设置返回结果确认后，展示开通请求结果，如不设置，可点击“暂不设置”（直联签约成功后可前往系统设置-银企直联-设置与查询下进行设置），点击提交 。 



![2.2.1UBank签约 图12](assets/2.2.1UBank签约-12.png)




![2.2.1UBank签约 图13](assets/2.2.1UBank签约-13.png)


（5）另一个管理员，可从自助申请-审批进入审批界面。



![2.2.1UBank签约 图14](assets/2.2.1UBank签约-14.png)


 或者从待办通知进入审批界面。 



![2.2.1UBank签约 图15](assets/2.2.1UBank签约-15.png)


 找到对应的审批记录，查阅无误后，点击同意 



![2.2.1UBank签约 图16](assets/2.2.1UBank签约-16.png)




![2.2.1UBank签约 图17](assets/2.2.1UBank签约-17.png)




![2.2.1UBank签约 图18](assets/2.2.1UBank签约-18.png)


（6）阅读协议，确认开通费



![2.2.1UBank签约 图19](assets/2.2.1UBank签约-19.png)




![2.2.1UBank签约 图20](assets/2.2.1UBank签约-20.png)




![2.2.1UBank签约 图21](assets/2.2.1UBank签约-21.png)




![2.2.1UBank签约 图22](assets/2.2.1UBank签约-22.png)


（7）签约完成后，可在自助申请-经办-已申请菜单查看。



![2.2.1UBank签约 图23](assets/2.2.1UBank签约-23.png)


 签约完成后，系统会对开通费用进行实时扣收，扣费成功，云直联开通成功。 开通成功后，如果在签约过程中没有进行直联业务设置，则签约完成后，还需要进行银企直联相关业务的设置（见2.3设置） 。
