2.报文规范 

 报文格式： JSON

 编码要求： UTF-8

控制类信息（HEAD）+业务类信息（BODY） ﻿ 

 请求报文大小限制：小于10M 

 数据类型说明： 

 注意：所有值请用字符串，如：正确："trsamt": “116.01”,错误："trsamt": 116.01。 

 请字段值不要包含如下特殊字符：“\”、“|”以及一些不可见的字符如“\n”等。 

 String： 字符串类型，可输入中文，一个中文占3位长度

 JSONArray： json数组类型 

 JSONObject： json对象 

 Number(15,2)： 字符串类型，第一位表示总长度（不含小数点），第二位表示小数位数，如示例表示13位整数、2为小数。 

 Integer： 整数类型 ﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿
