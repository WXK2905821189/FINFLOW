1.并发限制

云直联支持请求并发处理，同一企业支付经办（BB1PAYOP）请求、代理清算经办（BB8OPAGP）请求各单独支持50并发，代发经办（BB6BTHHL）请求、代扣经办（BB6ACLAK）请求各单独支持20并发，其余请求合并并发限制为20并发，超过会报错。如果客户有超过20并发的场景请优先使用批量的接口提高并发处理能力，并在客户自己系统缓冲排队处理，避免触发并发报错。
