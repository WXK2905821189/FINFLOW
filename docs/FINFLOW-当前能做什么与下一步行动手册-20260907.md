## 三、本轮沉淀的关键铁律（复用）

1. **record 加组件必 grep 所有 `new Xxx(...)` 构造点**——聚合层重建点会静默吞字段（症状：老列有值新列全 null）。
2. **H2 红线**：一条 ALTER 只加一列；`selectMaps` 列名大写返回，聚合 key 大小写不敏感。
3. **重放一致性三要素**：状态走与入库同一条归一路径 + 还原 auxiliary 余额快照 + 带 pageTotals，否则必假报差异。
4. **record 普通方法 Jackson 不序列化**：要输出的标志位必须做成显式组件。
5. **并行会话卫生**：commit 严格 pathspec 限界；测试用全局 `~/.m2`；部署 jar 用 git archive 隔离构建。
6. **本地跑过 ≠ CI 绿**：push 后 `gh run watch` 到终态才算数（迁移断言 4 处同步：expected_versions / applied / validated / incremental）。
